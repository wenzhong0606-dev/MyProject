# G1–G6 质量门禁

| 门禁 | 检查对象 | 放行依据 |
|---|---|---|
| G1 | 业务需求 | 目标、角色、范围、验收标准明确 |
| G2 | 业务与领域模型 | 对象、状态、流程、规则无未解决关键冲突 |
| G3 | 产品原型 | 功能、权限、交互与异常路径覆盖 |
| G4 | 工程设计 | 数据、API、架构、安全、非功能需求可实现 |
| G5 | 开发完成 | 代码审查、自动化测试、追踪关系与缺陷满足要求 |
| G6 | 上线验收 | UAT、回滚、监控、运维准备完成 |

状态：NOT_STARTED / IN_PROGRESS / PASS / BLOCKED / WAIVED。WAIVED 必须注明批准人、理由、风险与有效期。AI 不能自行批准业务或安全门禁。未提供证据不得标记 PASS。
