# 09 开发实现 — implementation Deliverables

- **阶段职责**：执行编码和开发级验证
- **输入**：已批准的立项依据或上游已批准成果；引用时写明来源和版本
- **当前阶段状态**：NOT_STARTED（仅有模板）
- **适用门禁**：G5
- **输出**：本目录独立成果文件，满足对应评审标准后才能申请门禁

## 独立成果清单

| 文件 | 核心作用 | 使用边界 | 状态 |
|---|---|---|---|
| [implementation-plan-实施任务.md](./implementation-plan-实施任务.md) | 拆分可交付任务，标注依赖、负责人、估算与完成条件 | 不以计划表替代实际交付 | DRAFT |
| [implementation-log-实现记录.md](./implementation-log-实现记录.md) | 记录实现差异、关联提交、文件范围与设计变更 | 不伪造已实现功能 | DRAFT |
| [unit-test-report-开发自测.md](./unit-test-report-开发自测.md) | 记录真实执行的构建、单测、静态检查与失败证据 | 未运行时不得报告通过 | DRAFT |

## 阶段完成要求

必须完成内容评审、上下游一致性检查、追踪更新及人工门禁审批；模板存在不等于完成。详细职责见 [全量文件职责目录](../../governance/deliverables-catalog-交付物职责清单.md)。
