## 一、职责和意义 Purpose

界定产品包含、不包含的业务及阶段边界。

## 二、输入 Input

记录已核实的需求、上游文档版本、业务依据、相关负责人及引用地址；未取得的证据写「待确认」。

## 三、必须包含的内容 Required Output

1. **范围与对象**：界定本文档覆盖的业务对象和不覆盖的边界。
2. **详细成果**：界定产品包含、不包含的业务及阶段边界；明确结构、数据来源、决策依据及必要图表。
3. **规则与异常**：说明正常路径、边界条件、异常情况及业务责任。
4. **关联与追踪**：填写需求/功能/对象等稳定 ID 以及上下游文件链接。
5. **未决事项**：列出影响交付的缺口、风险、批准人及处理方式。
