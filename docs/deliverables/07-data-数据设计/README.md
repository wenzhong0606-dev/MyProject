# 07 数据设计 — data Deliverables

- **阶段职责**：定义数据组织和治理要求
- **输入**：已批准的立项依据或上游已批准成果；引用时写明来源和版本
- **当前阶段状态**：NOT_STARTED（仅有模板）
- **适用门禁**：G4
- **输出**：本目录独立成果文件，满足对应评审标准后才能申请门禁

## 独立成果清单

| 文件 | 核心作用 | 使用边界 | 状态 |
|---|---|---|---|
| [logical-model-逻辑数据模型.md](./logical-model-逻辑数据模型.md) | 将领域对象映射为逻辑实体、关系与键约束 | 不包含未经确认的生产建表命令 | DRAFT |
| [data-dictionary-数据字典.md](./data-dictionary-数据字典.md) | 规定字段含义、类型、是否必填、取值范围、默认值和来源 | 不混入 UI 文案清单 | DRAFT |
| [data-lifecycle-数据生命周期.md](./data-lifecycle-数据生命周期.md) | 描述数据创建、变更、归档、删除、保留和审计策略 | 不代替真实数据操作日志 | DRAFT |
